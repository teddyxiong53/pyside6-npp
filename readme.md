# NPP 文本编辑器

基于 PySide6 开发的现代化文本编辑器，复刻 Notepad++ 核心功能

## 主要功能

✅ 多标签文档编辑  
✅ 语法高亮（支持 Python/HTML/CSS/JS 等）  
✅ 查找替换（支持正则表达式、大小写匹配）  
✅ 编码格式自动识别  
✅ 自定义字体和界面缩放  
✅ 文档大纲导航  
✅ 自动保存/恢复会话  
✅ 跨平台支持（Windows/macOS/Linux）

## 安装要求

```bash
# 安装依赖
pip install PySide6
```

## 快速开始

```bash
python app.py
```

## 使用指南

1. **文件操作**  
   - 新建文件：⌘N  
   - 打开文件：⌘O  
   - 保存文件：⌘S

2. **编辑功能**  
   - 撤销/重做：⌘Z/⌘⇧Z  
   - 查找替换：⌘F / ⌘⌥F  
   - 跳转行号：⌘G

3. **视图设置**  
   - 调整字体：视图菜单 → 设置字体  
   - 缩放界面：⌘+ / ⌘-  
   - 切换暗色主题：正在开发中
